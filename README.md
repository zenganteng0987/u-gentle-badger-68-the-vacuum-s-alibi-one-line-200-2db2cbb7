## What it does

`main.ts` writes a single line — the funniest excuse a robot vacuum can give for missing a spot, 200 characters or fewer — to `/output/entry.txt`, with no trailing newline.

> I did not miss that spot. My sensors classified it as 'decorative dirt,' my schedule rescheduled it for never, and frankly, at 12% battery, it can wait for someone with legs.

## Run

```sh
node main.ts
```

Requires Node 22 or later. No network, no dependencies.
